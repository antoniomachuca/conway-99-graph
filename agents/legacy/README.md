# Legacy Agent Scripts and Historical Briefings

This directory contains historical agent scripts from the initial setup and early development phases of the project:

- `agent_a_orbit_reduction.py`: Early prototype for orbit reduction. The maintained implementations reside in `scripts/`.
- `agent_b_cnf_compiler.py`: Early prototype for CNF compilation. Maintained versions reside in `scripts/`.
- `agent_c_auditor.py`: Early auditor script.
- `agent_d_lean_formalizer.py`: Early Lean formalizer helper script.
- `orchestrator.py`: Early orchestrator script (also mirrored in `scripts/orchestrator.py`).
- `AGENT_HANDOVER_BRIEFING_20260920.md`: Historical handover briefing from 20 September 2026. The active, authoritative audit log is `agents/audit_log.md`.
