# Z7 exterior row-problem certificate

**Goal:** Obtain a DRAT-checked refutation of the exact 12×12 row problem already enumerated, and derive that problem from `Z7OrbitMatrix` in Lean.

**Architecture:** `scripts/z7_row_problem_cnf.py` encodes one `RowProblem`. Upper-triangle variables express matrix symmetry, not a relabeling cut. Sums are one-hot dynamic programs. `scripts/solve_z7_row_problem.py` writes the CNF, runs the repository CaDiCaL and `drat-trim`, and records hashes. A Lean lemma may derive the exterior equations. It does not import the DRAT proof, so `z7_orbit_matrix_nonexistence` stays a `sorry`.

**Tech stack:** Python 3.12, PySAT `CardEnc`-free DP clauses, CaDiCaL 1.9.5, `drat-trim`, Lean 4.

**Frozen predicate:** `/Volumes/Untitled/conway_z7_enumeration_20261003_01/manifest.json`, field `row_problem`.

## Constraints

- No Frob(21) blocks, no zero-diagonal force, no orbit relabeling cuts.
- A verified DRAT proves only the emitted CNF.
- Taxonomy stays **PROVED** only when the solver log contains `s UNSATISFIABLE` and the checker log contains `s VERIFIED`.
- Do not delete prior artifacts or overwrite an output directory.

## Tasks

1. Encode `RowProblem` and test it against brute force on the existing small problems, including all 12 labelled 5-cycles.
2. Emit the Z7 CNF into a new external-drive directory and run CaDiCaL plus `drat-trim` under time, proof-size, and free-space limits.
3. Record the terminal manifest. If both verdicts match, the formula is **PROVED** at CNF scope.
4. Prove in Lean that a `Z7OrbitMatrix` supplies an exterior block obeying those equations. Leave the nonexistence `sorry` in place.
